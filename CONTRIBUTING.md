# Contribuir

Describe el problema, la versión de Windows y SA-MP. Ejecuta npm test y npm run dist. Comprueba ambos tamaños de ventana, selección de servidor, nombre, ruta e inicio directo con un GTA de prueba.

El alcance es un launcher simple: Servidores y Configuración. No añadas gestión de mods ni Addon. Para actualizar samp-versions.json, verifica la descarga, SHA-256 y samp.dll; conserva las fuentes y recompila el asistente nativo. No incluyas instaladores de terceros ni archivos del juego en el repositorio.

Contribuciones de código bajo MIT. Las ilustraciones y tipografías de terceros conservan sus derechos.
